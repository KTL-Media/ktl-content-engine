# PLATFORM — Content-to-Client Loop

GIT BUILT / Imaginarium. One loop, five playbooks, one standing rule:

**NOTHING is emailed, sent, posted, shared, activated, or published without
Phillip approving the exact content first.** Every playbook's PROOF.md enforces it.

## The chain

```
1. content-intake   Long-form in  → source.mp4 + audio.wav + transcript.json
2. clip-producer     Transcript    → 3–5 rendered 1080×1920 clips (karaoke captions)
3. publisher         Clips         → captioned, scheduled, Phillip-approved posts
4. lead-capture      Comments      → PLAYBOOK keyword → DM → email → starter kit
5. lead-nurture      Leads         → follow-up sequence → booked clients
```

## Handoff artifacts (each playbook's output is the next playbook's input)
