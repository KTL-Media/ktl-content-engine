# PROOF — publisher

The gate before anything goes public. Run per post, not per batch.

- [ ] Caption drafted: hook line + context + CTA + 3–5 hashtags
- [ ] 2 hook variants offered; Phillip picked or rewrote
- [ ] Target account named explicitly (`@phil_moreland` or brand)
- [ ] Scheduled time proposed (7–9am or 12–1pm ET)
- [ ] **Approval gate:** Phillip approved the EXACT clip file, the EXACT caption
      text, the EXACT account, and the timing. Verbal, per post. No batch
      approvals, no "you know what I like." Unapproved = unposted, full stop.
- [ ] Post URL logged to the work dir after publishing
- [ ] `lead-capture` notified: post URL + keyword to listen for

Checklist version: publisher v1. Only publish work that passes 100%.
