# PROMPTS — publisher

## 1. Process prompt

> Act as a world-class operations consultant. I want to document my process for
> PUBLISHING — turning finished vertical clips into posted Instagram Reels —
> so an AI agent can execute it exactly the way I do. The agent drafts captions
> (hook + context + CTA + hashtags), proposes schedules, and posts via
> `05_ship.py` or the IG app — but NOTHING posts without my explicit approval
> of the exact clip, exact caption, exact account, and timing, per post.
> Interview me ONE question at a time. Ask about: my caption formula; when the
> CTA is "Comment PLAYBOOK" vs a plain follow CTA; my hashtag rules; posting
> frequency and time windows; which account gets what; what my approval looks
> like (and what doesn't count as approval); how I want approvals logged; what
> "done right" looks like; the mistakes a beginner always makes (batch
> approvals, weak hooks, hashtag stuffing). Keep asking until you can write the
> full process back as a numbered SOP. Ask your first question now.

## 2. Toolbox prompt

> Build the TOOLBOX for my publisher playbook. It must contain: the caption
> template (hook + context + CTA + hashtags); the two CTA blocks (PLAYBOOK lead
> magnet vs plain follow); the hashtag bank; the 2-hook-variant format (≤12
> words each); the schedule (1/day max, 7–9am and 12–1pm ET, format alternation);
> the 05_ship.py command; the account list (@phil_moreland, imaginarium2026);
> and the approval log format. Keep it tight, no fluff.

## 3. Proof prompt

> Build the PROOF checklist for my publisher playbook, run per post. Items:
> caption drafted to template; 2 hook variants offered and decided; target
> account named; time proposed; then the approval gate — I approved the EXACT
> clip, EXACT caption, EXACT account, and timing, verbally, per post; no batch
> approvals; unapproved = unposted. Then: post URL logged; lead-capture
> notified with post URL + keyword. End with a version label and the rule: only
> publish work that passes 100%.

## 4. Correction prompt

> My publisher playbook got something wrong. Don't re-prompt me in the chat —
> fix the playbook files instead. Diagnose first: was PROCESS.md unclear
> (caption formula, approval flow)? Was TOOLBOX.md missing a template, CTA, or
> hashtag? Was PROOF.md too weak to catch the failure — especially the approval
> gate? Then edit the right file and tell me in one line what changed and which
> future runs it fixes. If it's a judgment call I need to make, ask me one
> direct question instead of guessing.
